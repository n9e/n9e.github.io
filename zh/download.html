你要做什么

先试试

五个容器：n9e、MySQL、Redis、VictoriaMetrics，以及采集本机的 Categraf。

git clone https://github.com/ccfos/nightingale.gitcd nightingale/docker/compose-bridgedocker compose up -d

起来之后

  1. docker compose ps 能看到五个容器在运行
  2. 打开 http://localhost:17000，用 root / root.2020 登录
  3. 自带的 Categraf 已经把本机上报上来，机器列表里能看到它

Docker Compose 部署文档 →

同一目录下的其他组合

  • compose-postgres把 MySQL 换成 PostgreSQL 12
  • compose-host-network存储换成 Prometheus，host 网络，仅 Linux
  • compose-host-network-metric-log再加 Kafka、Elasticsearch、Logstash 跑日志，仅 Linux
