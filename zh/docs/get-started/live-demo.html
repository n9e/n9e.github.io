在线体验导览

登录公共演示环境，按快速开始的顺序走一遍：从数据源到告警送达，不用安装任何东西。

最后校对于 2026-10-10

看完这页，你会在一个运行中的夜莺上走完一条告警经过的每一站：它读的数据源、判定它的规则、它产生的事件，以及把它送出去的通知规则。

登录​

打开 在线演示环境。这个链接会自动以公共演示账号登录，不用输入账号密码。

预期结果：进入 首页，顶部是 新手引导 清单。演示环境就是开源版，这里看到的每个菜单，按快速开始装出来的实例里都有。

这个环境所有访客共用，不要在里面填真实的密码、Webhook 地址、手机号或 API Key。

导览路线​

按下面的顺序点左侧菜单，每一站对应快速开始里的一步。

  1. 集成中心 → 数据源。夜莺在原地查询这些数据源，数据不会被搬进来。点开一个，看它的地址和超时设置。预期结果：一列数据源，每个带类型图标，比如 Prometheus。
  2. 数据查询 → 指标。选一个数据源，查一条 up 这样的语句。告警规则用的是同一种查询语言，这里能查出数据的语句，放进规则里也能用。预期结果：一张曲线图和一张时间序列表格。
  3. 告警通知 → 告警规则。先在左侧选一个业务组，再点开一条规则，看三样东西：查询语句、每个级别（S1 / S2 / S3）的阈值，以及过滤毛刺用的持续时长。
  4. 告警通知 → 告警事件。活跃告警 是仍在告警的，历史告警 保留所有事件，含已恢复的。点开一个事件，看它的标签、触发时的值，以及它发出了哪些通知（两张列表的区别）。
  5. 告警通知 → 通知规则。事件在这里匹配到人和通知媒介。同一菜单下的 通知媒介 和消息模板 决定消息怎么发、长什么样。
  6. 数据查询 → 仪表盘。基于同样数据源的图表。如果你已经在用 Grafana，可以继续用，这里的仪表盘不是必需的。

下一步​

用快速开始拉起你自己的实例，或者直接去写第一条告警规则。
