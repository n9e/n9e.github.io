# 选一条路进来

按你手上已有的东西，从四个起点里挑一个。每条路的终点都是一条在真实数据上跑起来的规则。

## [已有 Prometheus / VictoriaMetrics](https://n9e.github.io/zh/docs/get-started/choose-your-path/existing-metrics.md)

[把现有存储注册为数据源，抓取配置原样保留，让第一条规则在它上面跑起来——数据不用搬。](https://n9e.github.io/zh/docs/get-started/choose-your-path/existing-metrics.md)

## [已有日志库或数据库](https://n9e.github.io/zh/docs/get-started/choose-your-path/existing-logs-databases.md)

[用和指标同一套规则体系，对 ElasticSearch、Loki、ClickHouse、MySQL 这类日志库和数据库做告警。](https://n9e.github.io/zh/docs/get-started/choose-your-path/existing-logs-databases.md)

## [还没采集，从 Categraf 开始](https://n9e.github.io/zh/docs/get-started/choose-your-path/categraf.md)

[在一台机器上装 Categraf，通过 Remote Write 指向夜莺，一分钟内在对象列表里看到它上线。](https://n9e.github.io/zh/docs/get-started/choose-your-path/categraf.md)

[配置一个大模型提供方，打开内置助手和 MCP 端点，再接上 Claude Code 这类客户端。](https://n9e.github.io/zh/docs/get-started/choose-your-path/nightingale-ai.md)
