# 集成模板

86 个模板把采集配置、仪表盘、告警规则打成一套，一个组件一次接完。

## [安装采集配置](https://n9e.github.io/zh/docs/data/integrations/collector-config.md)

[把模板里的采集配置放进 Categraf，开始采集该组件的指标。](https://n9e.github.io/zh/docs/data/integrations/collector-config.md)

## [导入仪表盘与规则](https://n9e.github.io/zh/docs/data/integrations/import.md)

[把模板附带的仪表盘和告警规则导入某个业务组，启用前调整阈值。](https://n9e.github.io/zh/docs/data/integrations/import.md)

## [验证数据到达](https://n9e.github.io/zh/docs/data/integrations/verify.md)

[导入的规则不响可能只是数据没到；用集成模板列出的指标名在即时查询里查一次，两分钟就能确认组件指标已经到达。](https://n9e.github.io/zh/docs/data/integrations/verify.md)
