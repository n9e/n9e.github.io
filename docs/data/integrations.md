# Integration templates

86 templates that bundle collector config, dashboards and alert rules so a component is onboarded as a set.

## [Install collector configuration](https://n9e.github.io/docs/data/integrations/collector-config.md)

[Copy a template's collector config into Categraf and start collecting the component's metrics.](https://n9e.github.io/docs/data/integrations/collector-config.md)

## [Import dashboards and rules](https://n9e.github.io/docs/data/integrations/import.md)

[Import the bundled dashboards and alert rules into a business group, and adjust thresholds before enabling.](https://n9e.github.io/docs/data/integrations/import.md)

## [Verify incoming data](https://n9e.github.io/docs/data/integrations/verify.md)

[A quiet imported rule may just mean no data arrived; query the metric name the template lists in the Metrics explorer to confirm the component's metrics are in.](https://n9e.github.io/docs/data/integrations/verify.md)
