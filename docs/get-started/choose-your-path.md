# Choose your path

Four starting points depending on what you already run. Each one ends with a rule evaluating real data.

## [I already have Prometheus / VictoriaMetrics](https://n9e.github.io/docs/get-started/choose-your-path/existing-metrics.md)

[Register the store as a data source, keep scraping exactly as before, and get the first rule evaluating against it — no data moves.](https://n9e.github.io/docs/get-started/choose-your-path/existing-metrics.md)

## [I already have logs or databases](https://n9e.github.io/docs/get-started/choose-your-path/existing-logs-databases.md)

[Alert on ElasticSearch, Loki, ClickHouse, MySQL and the other SQL-queried stores using the same rule model as metrics.](https://n9e.github.io/docs/get-started/choose-your-path/existing-logs-databases.md)

## [I need to monitor a host with Categraf](https://n9e.github.io/docs/get-started/choose-your-path/categraf.md)

[Install Categraf on a host, point it at Nightingale over Remote Write, and see the machine appear under Targets within a minute.](https://n9e.github.io/docs/get-started/choose-your-path/categraf.md)

## [I want to enable Nightingale AI](https://n9e.github.io/docs/get-started/choose-your-path/nightingale-ai.md)

[Configure an LLM provider, turn on the built-in assistant and the MCP endpoint, and connect a client such as Claude Code.](https://n9e.github.io/docs/get-started/choose-your-path/nightingale-ai.md)
