Query and dashboards

Look at the data before you alert on it: the metrics and log explorers, built-in views, and dashboards you can share or embed.

Metrics explorer

Ad-hoc PromQL against any registered source, with the same query editor rules use.

Built-in metric views

Pre-built views for hosts, containers and common middleware, and how to add your own.

Object quick view

From a host in the target list to its key metrics in one click.

Log explorer and index patterns

Search ElasticSearch, Loki and VictoriaLogs sources, define index patterns, and pivot from a log line to a rule.

Recording rules

Precompute expensive expressions on a schedule and alert on the result instead.

Build a dashboard

A dashboard belongs to a business group; build it from an integration template or from scratch with twelve panel types, and export it whole to hand to someone else.

Variables and filters

Dashboard variables add dropdowns at the top of a board, populated from label values and chained to each other; pick a host or a cluster and every chart switches.

Anonymous time-limited sharing

Share one dashboard through a link that expires, without creating an account for the viewer.

Share, embed and integrate external systems

Embed Nightingale into an existing portal, hide menus selectively, and pass identity through.

Use Grafana with Nightingale

Keep Grafana for visualisation: point it at the same stores, and hand alerting to Nightingale.
