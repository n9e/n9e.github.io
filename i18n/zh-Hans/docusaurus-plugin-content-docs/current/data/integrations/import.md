这页办完你会得到：某个业务组下多了这个组件的仪表盘，以及一批**处于停用状态**的告警规则，
等你改完阈值再逐条启用。

夜莺内置了 {figures.integrations} 个组件的模板。指标采上来之后，不用自己从零画图、从零写规则——
把模板导进业务组，改改阈值就能用。

## 一个组件带哪些东西

**集成中心 → 模板中心**，点开任意一张组件卡片，抽屉里有四个页签：

| 页签 | 内容 |
|---|---|
| 采集说明 | 这个组件怎么采，见[安装采集配置](./collector-config.md) |
| 指标说明 | 这个组件会产出哪些指标、每个指标什么意思 |
| 仪表盘 | 现成的仪表盘模板 |
| 告警规则 | 现成的告警规则模板 |

不是每个组件四样都全。{figures.integrations} 个组件里，{figures.integrationsWithAlerts} 个带告警规则、{figures.integrationsWithDashboards} 个带仪表盘、{figures.integrationsWithMetrics} 个带指标说明。

## 导入仪表盘

在组件抽屉的 **仪表盘** 页签，表格列是「名称 / 标签 / 备注 / 更新人 / 操作」。
系统内置的那些，更新人一列显示「系统内置」。

勾选想要的那几行，点 **导入业务组**。弹窗里两项：

| 字段 | 说明 |
|---|---|
| 业务组 | 导到哪个业务组。**必须选到叶子节点**，中间层级不行 |
| 内容 | 已经按你勾选的模板填好了 JSON，一般不用动 |

点 **克 隆** 完成。之后去 **数据查询 → 仪表盘**，切到那个业务组就能看到。

导入是**一次性拷贝**：之后夜莺升级、模板更新了，已经导过的仪表盘不会跟着变；
想要新版本就重新导一次。

**面板里的数据源不在导入时选**，是打开仪表盘时选的——所以同一个模板导一次，
可以对着不同的数据源看。

## 导入告警规则

在 **告警规则** 页签，勾选要导的规则，点 **导入业务组**。这个弹窗比仪表盘多几项：

| 字段 | 说明 |
|---|---|
| 业务组 | 同上，必须是叶子业务组 |
| 启用 | **默认关闭。** 保持关闭，等阈值改完再逐条打开 |
| 数据源类型 | 只读，从模板本身推导出来。内置规则基本都是 `prometheus` |
| 数据源 | 选这批规则跑在哪个（哪些）数据源上。旁边有「数据源预览」 |
| 通知规则 | 事件往哪儿发，可以现选也可以现建 |
| 内容 | 已经填好的规则 JSON |

点 **导 入** 完成。

一次只能导**同一种数据源类型**的规则。混选了不同类型，弹窗会提示
「无法导入不同数据源类型的告警规则」并禁掉提交按钮——分两次导即可。

## 另一个入口：从仪表盘页和规则页导

不想先进模板中心的话，反过来也行：

- **数据查询 → 仪表盘 → 选中业务组 → 导入**，弹窗第一个页签就是 **导入内置仪表盘**：
  先选**组件**，再在**模板**表格里勾选。这个表格多一列「变量」，
  可以在导入前先把仪表盘变量调好；
- **告警通知 → 规则管理 → 选中业务组 → 导入**，第一个页签是 **导入内置告警规则**，
  比上面多一个**分类**下拉框（同一个组件常常有 `xxx_by_categraf` 和 `xxx_by_exporter`
  两套规则，按采集方式分开）。

两个入口拿的是同一批模板，走的是同一个接口，选哪个看你当时在哪个页面。

这两个「导入」按钮只在**选中了叶子业务组**时才出现。

## 第三个入口：数据源保存后的一键导入

新建 Prometheus 类型的数据源、保存成功之后，结果页会做一次模板匹配：
它把内置模板里的哨兵指标拼成一条查询打到你的数据源上，
**哪些哨兵指标最近有数据，就说明对应组件的数据已经在了**，然后把这些组件列成卡片：

> 已在这个数据源里发现 3 个组件的数据，点击卡片导入模板

点卡片直接进导入弹窗，仪表盘和告警规则分两个页签，各自标着数量。
这条路只对 **Prometheus 系数据源**有效，而且判定的是「最近有数据」，不是「历史上有过」。

## 启用前先改阈值

内置规则的阈值是**通用默认值**，不是给你的环境定的。导进来之后至少过一遍这三样：

1. **阈值**。「CPU 利用率 > 90%」在压测机上是常态，在数据库主库上是事故；
2. **持续时长**。抖一下就报的规则很快会被无视，先看看这个指标平时抖多大；
3. **通知规则和级别**。S1 该叫醒人，S3 不该。

改完再把「启用」打开。一次全开是常见的翻车方式——
先开五条最要紧的，观察一周，再开下一批。
