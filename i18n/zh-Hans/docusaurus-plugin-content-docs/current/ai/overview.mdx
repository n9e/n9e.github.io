v9 起，`n9e` 进程自身就是一个 MCP Server。不用多部署一个组件：端点就在你已经跑着的那个进程里。

## 接入客户端

Claude Code、Cursor 等支持 MCP 的客户端直连 `/mcp`：

```json title="~/.claude.json"
{
  "mcpServers": {
    "nightingale": {
      "type": "http",
      "url": "http://127.0.0.1:17000/mcp",
      "headers": { "X-User-Token": "<your-token>" }
    }
  }
}
```

## 客户端能做什么

**13 个工具集共 74 个工具**——42 个读、32 个写：

`alerts` · `targets` · `datasource` · `mutes` · `busi_groups` · `notify_rules` ·
`alert_subscribes` · `event_pipelines` · `users` · `metrics` · `logs` · `dashboards` · `roles`

每次工具调用都带着你的 token 落到夜莺自己的 HTTP API 上，因此**客户端拿不到 token 主人看不到的
东西**——权限模型与该用户在页面上完全一致。

## 鉴权

个人 Token 或 OAuth 2.1。夜莺可以自己做授权服务器，让 Claude、ChatGPT 这类托管客户端零预注册
接入；也能作为资源服务器，对接企业既有的 Keycloak、Entra ID、Okta。

:::note 写工具默认不注册
32 个写工具要在配置里显式打开才会注册。
:::
