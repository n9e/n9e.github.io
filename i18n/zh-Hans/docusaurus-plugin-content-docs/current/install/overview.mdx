| 方式 | 适用场景 |
|---|---|
| Docker Compose | 评估与中小生产环境——依赖组件一并拉起 |
| Docker 镜像 | 已有 MySQL 和时序库 |
| 二进制 | Linux amd64 / arm64 的 tar.gz，随 GitHub Release 附校验值 |
| Helm | Kubernetes |
| `n9e-edge` | 与中心网络链路不稳的边缘机房 |

各方式的具体命令见[下载页](/download)。
